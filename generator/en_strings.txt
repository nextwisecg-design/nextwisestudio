The venue ran four activities out of one kitchen, each with its own records. We brought them into a single role-based system that runs on a server on their premises. The system is internal, which is why it has no public address, and it is being rolled out.
What we did
Shared calendar
Rooms, halls, events and catering in one calendar, synced with Google Calendar.
Table orders
A web app on the waiter's phone. The order reaches the bar, the kitchen and the existing till system.
Bar and kitchen screens
Orders appear in real time on the kitchen TV and on the phone.
Event configurator
A public page in Romanian, English and German: packages, extras, the hall shown in 3D and a deposit paid online.
Kitchen
Requirements per event calculated from the recipe book, hours, staff, mise en place and waste.
Tasks
Per person, with time worked tracked. An agent offers to take the tasks it can do by itself.
Suppliers
Compares offers, proposes the order and sends it only after a “yes”, within fixed limits.
Daily figures
Sales, occupied tables, stock and margin per plate, read from the till system.
Confirmations, final guest count, reminders and review requests.
The management companion with daily proposals, the occupancy agent, the kitchen companion and the assistant on the events page.

Technical sheet
Hosting
local server, on the premises; works without internet too
Application
Next.js 16, React 19, TypeScript
Database
PostgreSQL 17, 20 SQL migrations
Real time
LISTEN/NOTIFY → Server-Sent Events, with a fallback refresh every 10 s
Sync
Google Calendar one-way; queue written by a trigger in the same transaction, retry from 1 to 60 min
Agents
Claude API with the client's key; limits checked in a trigger, the proposal validated at COMMIT
Access
roles and permissions enforced on the server, sessions in the database, audit log
Tests
376 code tests (Vitest) and 197 browser tests (Playwright), on three screen sizes, on every change
Monitoring
alert when a service is down or the backup is older than 26 h, external heartbeat
Backup
daily, encrypted
Ownership
the code, data and accounts are in the client's name
